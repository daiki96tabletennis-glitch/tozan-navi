📖 サイトに反映する手順
1
上のフォームで内容を修正する
アクセス時間・CC・YAMAPリンクなどを編集してください。変更すると保存ボタンが表示されます。
2
「mountains.json をダウンロード」を押す
ボタンを押すと mountains.json がダウンロードされます。このファイルに全山のデータが入っています。
3
GitHubを開く
github.com/daiki96tabletennis-glitch/tozan-navi ↗ を開いてログインしてください。
4
data/mountains.json を開く
リポジトリの data フォルダの中にある mountains.json を開きます。
5
✏️ ボタンで編集モードにする
右上の鉛筆アイコン（Edit this file）をクリックします。
Edit this file
6
全テキストを選択して貼り付ける
GitHub の編集画面で Ctrl+A（Mac: ⌘A） で全選択 → 削除 → ダウンロードした mountains.json の中身をコピペして上書きします。
① テキストエディタ（メモ帳・VSCode等）で mountains.json を開く
② Ctrl+A → Ctrl+C で全コピー
③ GitHubの編集画面で Ctrl+A → Ctrl+V で貼り付け
7
「Commit changes」で保存する
ページ下部の「Commit changes」ボタンを押せば完了。1〜2分で全ページに自動反映されます。
Commit changes
⚠️ 注意：mountains.jsonを更新しただけではサイトのHTMLファイルは変わりません。現在は管理画面での修正→JSONダウンロード→GitHubに反映後、Claudeに「最新のZIPを添付してページを再生成して」と依頼することで全ページに反映されます。
