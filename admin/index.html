📖 サイトに反映する手順
1
上のフォームで内容を修正する
アクセス時間・CC・YAMAPリンクなどを編集してください。変更するとコピーボタンが表示されます。
2
「修正内容をコピー」で記録する（任意）
Googleスプレッドシートやメモ帳に貼り付けておくと、修正履歴として残せます。
3
GitHubを開く
github.com/daiki96tabletennis-glitch/tozan-navi ↗ にアクセスしてログインしてください。
4
対象の山のファイルを開く
mountains/{山のID}/index.html を開きます。
例：高尾山なら mountains/takao/index.html
5
✏️ ボタンで編集モードにする
ファイルを開いたら右上の鉛筆アイコン（Edit this file）をタップします。
Edit this file
6
Ctrl+F（Mac: ⌘F）で該当箇所を検索して修正
修正箇所ごとに検索するキーワード：
アクセス時間data-dep="大船駅"
コース定数コース定数
YAMAPリンクyamap.com/mountains
バスリンクtransit.yahoo
規制バナーwarn-banner
7
「Commit changes」で保存する
編集後、ページ下部の「Commit changes」ボタンを押せばサイトに反映されます。
通常1〜2分で反映完了します。
Commit changes
