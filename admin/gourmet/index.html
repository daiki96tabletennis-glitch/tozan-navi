「山の茶屋・山小屋グルメ」の写真

  1. お店ごとの「候補を探す」を押すと、Wikimedia Commons から写真の候補が出ます（商用で使えるライセンスの写真だけ「使える」と表示）。
  2. そのお店・料理の写真かを確かめて「この写真にする」を押し、写真の説明（例：「みくりが池温泉の売店」）を確かめて「GitHubへ反映」。
  3. 数分で記事が自動で作り直され、写真の下に作者・ライセンス・Commons へのリンクが出ます。

料理名や山名で見つかった写真には注意が出ます。別のお店の料理を、そのお店のものとして載せないでください。お店の公式サイトの写真は使えません。

GitHub のトークンは、管理画面のトップで一度保存したものを使います（「山画像を管理」と同じ）。
